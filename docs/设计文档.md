- 开场仅乌萨斯突击者队长 ×1。最大生命 **164–168（167–171）**，进入战斗时当前生命为最大生命的 **50%（向下取整）**；获得 **战术撤退3**：“这名敌人将要在3回合后撤退。`[red]最好不要让它活着离开……[/red]`”。

- 第3回合援军从屏幕右侧跑入指定槽位：**左侧乌萨斯突击者、中间乌萨斯着铠术师、右侧乌萨斯突袭弩手**，下一敌方回合开始行动。队长成功撤退时援军无额外减益；队长倒地时，三名援军各获得**士气低迷2**：“这名敌人永久失去2点力量”。层数直接表示永久减少的力量。

## 苦难摇篮的教训（这次一开始就照做）

| # | 教训 | 在本模组怎么落实 |
|---|---|---|
| 1 | 难度要对齐原版的**类型平均**开局伤害，不是原版的单回合最高值；0.1.2 按最高值定上限，普通战均值做到 77，接近原版精英，玩家反馈“全是开幕雷击”。 | 先把原版荣耀 18 场照反编译搬进模拟器（`docs/tools/vanilla_glory.py`），本模组用同一引擎（`opening_sim.py`），按类型平均定目标；第 1 回合尽量留给格挡、强化、削弱。 |

- **第二次被击败**：直接死亡（播 `Die`）。重生时就移除复活机制与黑蛇之躯。火球不是爪牙，场上还有火球时战斗要等它们被打掉或爆炸才结束。
- **重生的触手**：重生落地特效 reborn_01_end 自带的黑冠与触手隐藏，回血那一刻就挂上常驻触手，从伸出到常驻是同一套（用户反馈过两套不连贯）。
- **技能时的触手爆发**：原作技能触手阵 skill_0x_start_04_reborn 的尖冠与 chushou 是常驻触手的预热副本，动画轨道在 10 帧内把触手的初速与力收到 0，
  触手缩回尖冠；0.9 秒起 chushou2 从尖冠直线射出一圈黑色尖刺（无力场、初速 10、只发 0.5 秒），1.05 秒爆闪。
  本模组只隐藏技能版的尖冠与 chushou（叠在常驻触手上是另一套临时触手，用户反馈），尖刺 chushou2 与爆闪照播；
  常驻触手自己照同一条轨道缩回，2.03 秒后从尖冠按原速重新伸出（AkFxPlayer.Retract，Talulah.RetractAura）。
  用户试过"常驻触手自己射出成尖刺再飘回"，最后定为这一版：0.3 秒常驻触手，0.6–1.05 秒收拢回尖冠，1.3–1.5 秒尖冠射出放射尖刺并爆闪，
  2.2 秒仅剩尖冠，2.8 秒触手重新伸出。
- **灾厄**：第一条命被灾厄击杀也要正确进入重生（教训 7）。
- Spine：黑蛇 `enemy_1515_bsnake`，19 个动画。`_A` 是第一条命，`_B` 是重生后；`Reborn_1_*` 是第一次倒下到重生落地；
  点燃与召唤 `Skill_1`，引爆 `Skill_2`，不息恶火 `Skill_3`，噬咬 `Attack`。
- 开局伤害（第一条命，前 4 回合）：点燃 0 / 噬咬 22 / 焦土 14 / 引爆 18，另加焦土的 2 张灼伤在第 4 回合末各 2 点，合计 58
  （A10 0 / 24 / 15 / 20 + 3 张灼伤 6，合计 65），引燃另计。点燃改为不攻击后比原版荣耀 Boss 的类型平均（83 / 94）低得更多，尚未补强，待用户定。

### A10 的双 Boss（需要你拍板）

原版 A10 含“双 Boss”（AscensionLevel.DoubleBoss）：最后一幕会从**本幕 Boss 池里排除主 Boss 后**再抽一个第二 Boss（`RunManager`，`act.AllBossEncounters.Where(e => e.Id != act.BossEncounter.Id)`）。
本幕只有塔露拉一个 Boss 时，排除后的池是空的，`NextItem` 返回 null，**A10 玩家在本幕只打一个 Boss**，比原版轻一截。可选：
- **（推荐）** 只在本幕是最后一幕且有双 Boss 时，从原版荣耀的三个 Boss 里随机抽一个当第一个 Boss，塔露拉放在最后打。
  - 需要补丁第二 Boss 的抽取。
  - 先打哪个 Boss 要实现时按原版地图核对。
- 接受只打一个 Boss，用塔露拉的 A10 数值补偿（不推荐：差距是一整场 Boss）。

    SpecialPoint0–3）以及是否跟着骨骼转；SpecialPoint 的组件里写着跟随的骨骼名（黑蛇：Weapon、Head、Hand、Wing）。
    tools/ak_vfx/attach.py 列出全部引用特效的挂点。挂在 SpecialPoint 上的特效都摆在立绘平面里（不跟骨骼转的朝向取单位朝向）：
    原作录像里黑蛇背后尖冠的高度与这样算出的一致，按世界坐标倾斜投影会矮一截。
    黑蛇第二条命常驻背后的触手是天赋特效 buff_04_start_reborn，技能里的触手阵、倒地与重生的符阵同一套，都挂在背后的 Wing 骨骼上，
    朝身后展开（原作 JT8-3 里黑蛇面朝右，本模组朝左，镜像后同样在身后）。对照录像：B 站 BV1S24y1C7Rj 约 4:17 起（二阶段）、3:36 起（转阶段）。
    用户反馈过三次触手位置不对。其他怪物的挂点也已照这张表改过（tools/ak_vfx/attach.py 列挂点，special_points.py 查 SpecialPoint 的骨骼与本地序号）：
    前锋的武器闪光在武器 C_L_Weapon_2、起手在脚下；突击者起手在脚下、闪光在武器 C_Weapon_03；术师、先兆者的起手在脚下；
    弩手的强化在背包 Bag_PQ；追猎者二形态连斩的起手在剑鞘 F_Scabbard；投射物都从 Muzzle 骨骼射出（原作同名骨骼）。

    （跟着转时前锋的刺光反向朝后）。转换器把挂点组件写进特效 JSON 的 attach 字段。

    同为挂点模式 A=10、带 rotation_y 的其他起手（前锋射击、突击者、术师）又在 +x，原作数据里分不出，是对照预览逐个定的。
    触手形状：粒子以初速度向后射出、受侧向恒力、超过限速时每帧削减，连成的带子是“初段直线 + 中段弧线 + 末段直线”。

    黑蛇倒下时的熔岩裂地、追猎者坍缩恐惧的范围圈与重整的范围、先兆者落点的瞄准标记。

    （黑蛇的黑色触手从她身后伸出，用户反馈过“触手连到原点”）。

    黑蛇噬咬 0.95–1.05 秒从身后经下方挥到身前，火焰剑气（同向旋转的弧）延后 0.9 秒、剑身爆闪延后 0.2 秒落在这一刀上；
    倒地、重生的特效随动作开始，自带节奏已对着动作里的音效事件。用户反馈过“动画刚开始特效就播完了”。
  - 快速模式：原版只等 min(一半, 0.25 秒) 就结算，动作却照原速播，伤害会落在蓄力动作上。本模组怪物在快速模式下与普通模式完全一样：
    动作从头原速播，等到动作里的出手那一帧再结算（src/Vfx/FlarePace.cs）。极速模式原版不等，照旧。
    先后否决过两种折中：动作与特效一起 2 倍速（加速的挥砍显得滑稽）、跳过动作开头一段蓄力（用户要求与普通模式一致）。
  - 战场环境（src/Vfx/BattlefieldBlast.cs）：原作 JT8-3 的关卡波次里有 17 次脚本动作 PLAY_OPERA blast_effect_x/y，
    远处爆炸、整个战场被火光映红、画面沿 x 或 y 震一下。效果本体在加密的关卡数据里读不到，参数对照通关录像（BV1PT4y1Q7cK）量：
    火光是逐像素的照亮而不是整屏加色：逐像素拟合得 R ×1.39 + 22、G ×1.25 + 5、B 基本不变（/255，到顶封顶），
    暗部只亮一点、中间调亮得多，对比度保住（第一版按平均值整屏加 (+40, +14, 0)，暗部被抬成橙灰，用户反馈"假"）。
    实现是放在原版前景特效层里读画面的着色器，照到战场与人物、不照界面。约 0.5 秒先快后缓升满，保持到 1.95 秒，越落越快到 2.9 秒消失；
    火光开始 0.24 秒后定向震屏约 1.1 秒（原版 ScreenShake 弱档、长档），
    相邻两次 16–24 秒，开战 3 秒后第一次。实时播放，与回合无关；不存档，联机各端各自随机。
  - 转阶段：不息恶火的三回合里她不在场，原作录像里她原来的位置是空地；原作 ScreenAttack 的光环 reborn_01_buff 不放在地上
    （第一版放在脚下，用户指出原作没有那块火斑）。倒下时的熔岩裂地 reborn_01_start_05 原作有，保留。
    远程招式改为命中前射出原作投射物，飞到后才结算伤害（多等飞行时间，结算本身不变）。
  - 预览：tools/ak_vfx/preview.py（设环境变量启动离线克隆的游戏窗口，摆怪物、播特效、截帧拼图）。镜头可写 monster + slot，
    直接读该怪物代码里的特效配置回放（slot 为 buff、death 或怪物自己给的特效组名时取强化、死亡、倒地等）。只是表现，联机各端各播各的。
